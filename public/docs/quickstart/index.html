Quickstart: Add Headless Oracle to Claude Code

One .mcp.json file. No npm install. No API key required to start. Your Claude Code session gets pre-trade market verification in under a minute.

1 Copy .mcp.json to your project root

Choose Anonymous (no key required; 10 get_market_status calls per IP per UTC day) or Authenticated (your API key's plan limit; needs an OAuth access token exchanged from your key):

Anonymous — no API key required 
{
  "mcpServers": {
    "headless-oracle": {
      "type": "http",
      "url": "https://headlessoracle.com/mcp"
    }
  }
}
Authenticated — first exchange your API key for an access token 
curl -X POST https://headlessoracle.com/oauth/token \
  -H 'Content-Type: application/x-www-form-urlencoded' \
  -d 'grant_type=client_credentials&client_id=YOUR_API_KEY_HERE'
# Returns: { "access_token": "…", "token_type": "bearer", "expires_in": 3600, "scope": "oracle:read" }
Authenticated — with the access token 
{
  "mcpServers": {
    "headless-oracle": {
      "type": "http",
      "url": "https://headlessoracle.com/mcp",
      "headers": {
        "Authorization": "Bearer YOUR_ACCESS_TOKEN_HERE"
      }
    }
  }
}

Auth: /mcp recognises only an access token from POST https://headlessoracle.com/oauth/token, which lasts one hour; request a new one when it expires. A raw API key sent as Bearer is not recognised, and the request is treated as anonymous.

Limits: Anonymous MCP allows 10 get_market_status calls per IP per UTC day. With a token, calls count against your key's plan: Free 500/day, Builder 50,000/day, Pro 200,000/day; only Protocol is unlimited. A free key needs no signup: POST /v5/keys/instant. A sandbox key (sb_, 200 calls over 7 days, one per IP) comes only from POST /v5/sandbox with {"email":"you@example.com"}; the key is in the response. Paid plans: headlessoracle.com/pricing.

2 Save the file as .mcp.json in your project root

Place it alongside your package.json or pyproject.toml. Claude Code reads this file on startup and loads the Headless Oracle tools automatically.

project-root/
├── .mcp.json          ← paste here
├── src/
└── package.json

3 Open Claude Code in that directory — tools are live

Start a new Claude Code session from your project directory. The Headless Oracle tools are available immediately. Try:

"Is NYSE open right now?"
"Check if XLON is trading before I run this script"
"What time does Tokyo open next?"
"Verify the market is open before executing this trade"

Available Tools

get_market_status
Ed25519-signed receipt (OPEN/CLOSED/HALTED/UNKNOWN) for any of 28 exchanges. Pre-trade verification gate. UNKNOWN and HALTED must be treated as CLOSED.
get_market_schedule
Next open/close times in UTC, holiday calendar, trading hours, and lunch break windows (Tokyo, HK, Shanghai).
list_exchanges
All 28 supported exchanges: NYSE, NASDAQ, London, Tokyo, Hong Kong, CME, Coinbase, Binance + 20 more.
get_payment_options
How to authenticate or pay before a request that needs a key or payment: sandbox, x402 per request, credits, subscriptions and the Chirindo Witness plans. No authentication required.

There is no MCP tool for verifying a receipt. Verify it with POST /v5/verify, or offline against the public keys at /v5/keys.

Need more than 10 calls a day?

Anonymous MCP stops at 10 get_market_status calls per IP per UTC day. A free key (500 calls/day) or a paid plan raises that limit; exchange the key for an access token as in step 1. Only the Protocol plan is unlimited.
